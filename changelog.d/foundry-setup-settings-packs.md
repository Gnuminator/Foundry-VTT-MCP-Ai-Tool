### Admin tools (D-135)

- **Foundry setup, part 1: settings and compendium packs:** the new `plan-foundry-setup` tool (Admin set) reads and plans changes to any world or client setting by `namespace.key` and to a compendium pack's configuration (who may open it per role, locked, folder). It goes through plan, confirm and undo like every AI write; undo puts the old value back, and a setting someone else changed in between is a conflict. Secret settings (keys, tokens, passwords) are never read or written, and the AI Tool's own switches, the role permission table and the module list cannot be changed this way. A new switch, "AI Tool: Foundry setup (writes)", is off by default. The Admin set budget grows from 8,000 to 10,500 characters for the three setup parts.

### Process tooling

- **Heavy-check lock:** `scripts/heavy-lock.mjs` is a machine-wide lock (one slot by default, `HEAVY_LOCK_SLOTS` for more, a folder under the temp directory) so only one heavy run goes at a time. `npm run green` takes it per heavy step (type check, lint ratchet, build, test suites, e2e), the pre-push hook per check, `lint:ratchet` around its ESLint pass and the merge gate's drift check around the lint, mcp-server and write-gate guards (through the script's CLI, since the gate's copy of `drift-check.mjs` may not import other files). A run that has to wait prints `heavy-lock: <run> waits for <holder> ...`, then every minute; a lock whose process is gone or older than 3 hours is taken over; after 60 minutes (or on any lock problem) the run goes on without the lock, so the lock never blocks the gate. Exit codes and output lines of the checks are unchanged. ESLint `--cache` is not used: the type-aware rules read other files' types, so a per-file cache can go stale.

### Obsidian (I-052 O6)

- **Quest import from Obsidian:** a quest note in your `Prep` folder (`type: quest-prep`, empty `fvtt_uuid`) becomes a GM-only quest journal in Foundry. In Obsidian run "Import this quest prep note into Foundry", then confirm the plan in the dashboard. It is off until you switch on "AI Tool: Obsidian import (writes)" in the module settings, and Undo removes the journal. It is not a Claude tool: only the plugin through the dashboard can start it, so the tool sets and their sizes are unchanged.

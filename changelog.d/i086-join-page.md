### Module

- **The Veil on the join page (I-086):** a GM-only "Join page look" button in the module settings
  gives Foundry's join page, the first screen players see, the campaign look: an original mist and
  castle background picture, the Veil fonts and a lamplit Join button. Foundry loads no module
  code on that page, so the button saves world details instead (the same request Edit World
  uses, no admin password): the background picture and one marked style line at the top of the
  world description. The GM's description text is kept; "Back to Foundry's look" removes the
  line and The Veil picture. The stylesheet only styles the join page, never the setup screen.

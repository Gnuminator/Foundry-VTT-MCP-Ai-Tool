### MCP server (I-124)

- **Tool hints on every tool:** each tool now carries MCP annotations: a short title, `readOnlyHint` and, on tools that change something, `destructiveHint`. Claude Desktop groups the 59 look-ups and plans as read-only, so the GM can allow them once instead of clicking "allow" on each look-up (the tool-pick test counted 0.6 to 0.8 clicks per request), and it keeps asking before the 27 tools that change something, `apply-planned-change` and `undo-change` among them. The `plan-*` tools count as reads: a plan only stages a change, and the apply asks. The table is `tool-hints.ts`; a test fails when a tool has no entry or a tool named like a write is marked read-only. The tool reference shows each tool's kind. Core and prep each grew about 1,500 characters, so their size budgets went up by 2,000.

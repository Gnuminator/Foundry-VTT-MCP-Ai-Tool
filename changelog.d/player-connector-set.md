### Tools

- **Player tool set (backend half of the player connector):** a sixth tool set `player` with five read-only tools (`get-my-character`, `get-my-level-up-options`, `search-books`, `find-book-entries`, `get-book-entry`) for a player's own Claude Desktop. It is never served on stdio and has no `call_tool` route: it runs only through the new control message `player_tool`, whose Foundry user id comes from the message (the dashboard's later `/mcp/player` route), never from the tool arguments. The new bridge query `playerRead` checks every actor (owner) and pack (observer) with that user, drops Adventure packs, world journals and actors, `dnd5e` and the Books pack, strips GM secret blocks from every passage and shows an unidentified item only under its unidentified name and text, caps excerpts and entries, and a last-line filter hides any book result that names Strahd, Barovia, Ravenloft, Tarokka, Ireena, Vallaki, a live Tarokka card or a term from an optional Pi config list (D-136; player-connector-set).

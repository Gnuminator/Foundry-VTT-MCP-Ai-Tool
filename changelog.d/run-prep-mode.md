### Module

- **Run mode and Prep mode:** a new "Run / Prep mode" button in the AI Tool group of the scene controls hides the Items, Roll Tables, Cards, Macros and Compendium tabs and the hotbar on that computer only. A "Run mode: show all" button stays on screen to bring everything back. It is CSS only and a per-client setting, so nothing is changed or deleted on the server (Backlog `run-prep-mode`).

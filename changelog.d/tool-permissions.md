### Dashboard

- **Tool permissions:** the GM can set each AI tool, or a whole tool set, to Allow, Ask me first or
  Deny (Advanced, Tool permissions). A tool on Ask is refused once and shows as a card; Allow once
  lets Claude's next try through. Only Claude's own calls are checked: the dashboard's buttons and
  the player set are not. Everything stays on Allow until changed. There is no spend meter
  (I-077).

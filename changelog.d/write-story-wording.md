### MCP tools

- **Honest write story for Claude:** the server instructions no longer say every write goes through plan, confirm and undo. They say that plan tools only prepare a change, that apply-planned-change makes it and undo-change takes it back, and that a tool marked "Direct write." acts at once and cannot be undone. About 25 direct-writing tools (rolls, chat, combat turns, scene switch, quests, NPC building and more) now start their description with "Direct write.". The "go ahead" and autoApply rule now lives only on apply-planned-change instead of being repeated on the plan tools.

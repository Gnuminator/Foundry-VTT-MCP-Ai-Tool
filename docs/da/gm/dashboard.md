# Dashboardet

Dashboardet er dit kontrolpanel under spillet. Denne side plejede at rumme hele rundturen; teksten ligger nu på disse sider (alle gamle sektionslinks lander stadig her og peger videre):

- [Dashboardet: visninger og header](dashboard-header.md): De tre visninger og headeren: forbindelsesmærke, Pre-flight, theme, session-knapper, GM Actions og Advanced-menuen.
- [Dashboardet: panelerne](dashboard-panels.md): During layouts, Combat Tracker, Tonight's stats, Session notes, Live Feed, Module Diagnostics og Recent Changes.
- [Dashboardet: confirm-vindue, Tool Runner og skuffer](dashboard-drawers.md): Confirm-vinduet, Tool Runner og skufferne Tarokka, Handouts, Prep og Party.
- [Dashboardet: spillersider og Obsidian](dashboard-player-pages.md): Spillersiden, afsløring af et handout, spillerlinks, My character og Open in Obsidian.

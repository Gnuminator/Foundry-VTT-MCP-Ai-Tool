# Quest: before a session

This is [Before each session](before-session.md) as a list you can tick off, about 15 minutes
before the players join. Each stage links to the steps on the checklist page, which has the full
wording and the fixes; this page keeps the order and the times. The rare cases stay on the
checklist page: the emailed login code, Dice So Nice's themed dice (once, before session 1) and
creature names on tokens already on the map.

:::note
Nothing to start on a PC and no terminal to open: the dashboard runs on the table's home server.
You need the game's address and the dashboard's address from the tool admin.
:::

**Progress:** four stages, ending with the session log running.

## Stage 1 of 4: Start everything (4 minutes)

Steps: [Start everything](before-session.md#start-everything).

- [ ] Claude Desktop is running.
- [ ] Foundry is open, the world is launched and you are in as GM.
- [ ] The dashboard is open on your second screen.
- [ ] The header looks calm: **✈ Pre-flight** is not red and no "Connection lost" mark shows.

**You are done when** the header looks calm. If it does not, see [Troubleshooting](troubleshooting.md).

## Stage 2 of 4: Pre-flight and switches (3 minutes)

Steps: [Run the pre-flight check](before-session.md#run-the-pre-flight-check) and
[Turn on what tonight needs](before-session.md#turn-on-what-tonight-needs).

- [ ] Click **✈ Pre-flight**. Fix everything marked ✗ and look at each **!**.
- [ ] Click **Turn on for tonight**.
- [ ] The [GM windows](gm-windows.md) setting is on.

**You are done when** the chips under the button show the switches as on.

:::tip
**End session** turns the switches off again, so you do not have to remember it afterwards.
:::

## Stage 3 of 4: What players will see (6 minutes)

Steps: [Check what players will see](before-session.md#check-what-players-will-see).

- [ ] The starting scene has a **Navigation Name** when its real name would give something away.
- [ ] Creatures the players already know have **Display Name** set to **Hovered by Anyone**.
- [ ] Tokens the players should not know about are hidden.
- [ ] The player page (`/player`) shows nothing that is a secret.
- [ ] Every page in your handouts journal is **None** unless you revealed it.
- [ ] In the Tarokka drawer, **Show cards** is not ticked.

**You are done when** the player page shows nothing you want to keep back.

## Stage 4 of 4: Prepare and begin (2 minutes)

Steps: [Prepare](before-session.md#prepare) and [When play begins](before-session.md#when-play-begins).

- [ ] In Claude Desktop, run the prompt `prep-next-session`.
- [ ] Read last session's note in Obsidian.
- [ ] Claude Desktop, the dashboard and Obsidian are on the screen the players cannot see.
- [ ] When play begins, start the session log from the dashboard header.

**You are done when** the header says "Session since" and the time.

## Quest complete

Play. Keep the [game night runbook](game-night-runbook.md) open. Afterwards: [after each
session](after-session.md).

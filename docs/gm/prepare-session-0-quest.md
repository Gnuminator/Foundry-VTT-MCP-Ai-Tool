# Quest: prepare session 0

This is [Prepare session 0](prepare-session-0.md) as a list you can tick off. That page has the
pictures and the reasons; this one has only the order. Do it a week or so before session 0. It
takes about 30 minutes, plus the test run.

:::note
Do the stages in order. Stage 3 is the one most likely to be half done already, and the one a
player notices first if it is not.
:::

**Progress:** five stages. The first two are about the players, the next two about the world, the
last one is a dress rehearsal.

## Stage 1 of 5: Emails (5 minutes)

- [ ] Ask each player in Discord for the email address they will use to join.
- [ ] Send the list to the tool admin. An address that is not on the admin's list never gets a
      login code, and gets no error either.
- [ ] Tell the players to use exactly the address they gave you.

**You are done when** the admin has said the list is in.

## Stage 2 of 5: One user per player (5 minutes)

- [ ] Press **Esc** and choose **User Management**.
- [ ] For each player, click **Create Additional User**, type their name in **User Name**, leave
      **Password** empty and keep the role **Player**.
- [ ] Click **Save and Return**.
- [ ] Send each player their user name in a Discord direct message, with the link to
      [Join the game](../player/join.md).

**You are done when** every player has a user and has their own user name.

## Stage 3 of 5: Characters (15 minutes)

In **Game Settings**, category **Core**, the **User Permissions** button:

- [ ] In the row **Create Actors**, the **Player** column is ticked. Click **Save Configuration**
      if you changed it.

In **Game Settings**, category **[Aardvark Games] Actor Studio (AI Tool fork)**:

- [ ] **Compendium Sources**, **Select sources**: untick **Show Selected Only**, tick the
      Player's Handbook packs in each row and untick the D&D 5e system's own packs. The table is in
      [Prepare session 0](prepare-session-0.md). Click **Save**, then **Yes** to reload.
- [ ] **Configure ability scores**: tick the one method you and the players agreed on.
- [ ] **Configure equipment & gold**: **Enable Equipment Selection** is ticked.
- [ ] **Configure spells**: tick **Enable Spell Selection**.
- [ ] **Configure progression**, under **Leveling Options**: tick **Enable Level Up** and
      **Milestone Levelling**. Without it nobody sees a **Level Up** button until they have the
      experience points.

:::tip
On our server the script has set **Create Actors**, the equipment and the Player's Handbook source
for equipment already. Check those three, and set the rest yourself.
:::

**You are done when** the species list shows only the 2024 species, a Cleric gets a **Spells**
tab and a new character's sheet has a **Level Up** button.

## Stage 4 of 5: The join page (5 minutes)

Optional.

- [ ] In **Game Settings**, category **Foundry AI Tool**, click **Choose join page look**.
- [ ] Keep or change **The lamplit line**, then click **Apply The Veil**.

**You are done when** the join page shows the castle in the mist, or you chose to keep Foundry's
look.

## Stage 5 of 5: Try it as a player (30 minutes)

- [ ] In User Management, make a user called **Test Player** with the role Player.
- [ ] Open the game in a private browser window and log in as Test Player.
- [ ] Follow [Make your character](../player/make-a-character.md) to the end.
- [ ] As GM, check the sheet with the checklist in step 10 of that page.
- [ ] Delete the character and the Test Player user.

**You are done when** a level-3 character came out right, from the first click to the checklist.

## Quest complete

On the night: post the link to [Make your character](../player/make-a-character.md) in Discord,
stay in voice, and go through the checklist with each player when they are done. The night itself
is in [Prepare session 0](prepare-session-0.md#on-the-night) and the agenda in
[Prep and expectations](prep-and-expectations.md#a-session-0-agenda-you-can-change).

# Quest: prepare session 0

This is [Prepare session 0](prepare-session-0.md) as a list you can tick off. That page has the
pictures and the reasons, and each stage below links to its steps; this one has only the order. Do
it about a week ahead of session 0; it takes half an hour, plus the test run. Players with the
game already open must reload (F5) after a setting change, before the builder. Leave usage
tracking off; it already is.

<!-- quest-skips: afterwards -->

:::note
Do the stages in order. Stage 3 is the one most likely to be half done already, and the one a
player notices first if it is not.
:::

**Progress:** five stages. The first two are about the players, the next two about the world, the
last one is a dress rehearsal.

## Stage 1 of 5: Emails (5 minutes)

Steps: [Collect the players' emails](prepare-session-0.md#0-collect-the-players-emails).

- [ ] Every player has told you, in Discord, the address they will join with.
- [ ] The list is with the tool admin. An address missing from it gets no login code and no error.
- [ ] The players know to type that address and no other.

**You are done when** the admin has said the list is in.

## Stage 2 of 5: One user per player (5 minutes)

Steps: [One user per player](prepare-session-0.md#1-one-user-per-player).

- [ ] Press **Esc** and choose **User Management**.
- [ ] Each player has a user with their name, no password and the role **Player**: use **Create
      Additional User**, then **Save and Return**.
- [ ] Each player has been sent their user name in a Discord direct message, with the link to
      [Join the game](../player/join.md).

**You are done when** every player has a user and has their own user name.

## Stage 3 of 5: Characters (15 minutes)

Steps: [Let players create characters](prepare-session-0.md#2-let-players-create-characters-a-check-on-our-server)
and [Point Actor Studio at the 2024 Player's Handbook](prepare-session-0.md#3-point-actor-studio-at-the-2024-players-handbook-partly-done-on-our-server).

In **Game Settings**, category **Core**, the **User Permissions** button:

- [ ] In the row **Create Actors**, the **Player** column is ticked. Click **Save Configuration**
      if you changed it.

In **Game Settings**, category **[Aardvark Games] Actor Studio (AI Tool fork)**:

- [ ] **Compendium Sources**, **Select sources**: the Player's Handbook packs are ticked in every
      row and the system's own packs are not (the table is on the checklist page). **Save**, then
      **Yes** to reload.
- [ ] **Configure ability scores**: one method is ticked, the one you and the players agreed on.
- [ ] **Configure equipment & gold**: **Enable Equipment Selection** is ticked.
- [ ] **Configure spells**: **Enable Spell Selection** is ticked.
- [ ] **Configure progression**, **Level Up Options**: **Enable Level Up** and **Milestone
      Levelling** are ticked. Without them nobody sees a **Level Up** button until they have the
      experience points.

:::tip
On our server the script has set **Create Actors**, the equipment and the Player's Handbook source
for equipment already. Check those three, and set the rest yourself.
:::

**You are done when** only 2024 species are offered, a new Cleric has a **Spells** tab, and a
fresh sheet shows **Level Up**.

## Stage 4 of 5: The join page (5 minutes)

Optional. Steps: [The campaign look](prepare-session-0.md#4-give-the-join-page-the-campaign-look-optional).

- [ ] In **Game Settings**, category **Foundry AI Tool**, click **Choose join page look**.
- [ ] Keep or change **The lamplit line**, then click **Apply The Veil**.

**You are done when** the join page shows the castle in the mist, or you chose to keep Foundry's
look.

## Stage 5 of 5: Try it as a player (30 minutes)

Steps: [Try it as a player](prepare-session-0.md#5-try-it-as-a-player).

- [ ] A user called **Test Player** with the role Player exists.
- [ ] You are logged in as Test Player in a private browser window.
- [ ] You followed [Make your character](../player/make-a-character.md) to the end.
- [ ] As GM, you checked the finished sheet against the checklist at the end of that page.
- [ ] The character and the Test Player user are deleted again.

**You are done when** a level-3 character came out right, from the first click to the checklist.

## Quest complete

On the night: share [Make your character](../player/make-a-character.md) in Discord, stay in
voice, and check each player's sheet when they are done. The night itself is in [Prepare
session 0](prepare-session-0.md#on-the-night) and the agenda in
[Prep and expectations](prep-and-expectations.md#a-session-0-agenda-you-can-change).

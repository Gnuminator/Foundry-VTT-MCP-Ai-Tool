# Send players their links

Gnuminator makes and sends the links before session 0, so you normally do not need this page. Use it
when a player loses their link or a new player joins.

Each player needs two things: the address of the player page, and their own private link to
**My character**. The D&D helper address needs nothing from you: the player finds it themselves on
My character. This takes a few minutes for the whole table.

Players already have their Foundry logins. They sign in to the player page and My character with the
same email code as Foundry.

1. **Open the dashboard** and click **Advanced**, then **🔗 Player links**. Every player in the world
   is listed.
2. **Click Make link** next to a player. The link is copied for you. If it is not, click **Copy link**.
3. **Send it in a private message (DM) to that player.** Never in a channel: whoever has the link
   sees that player's character. Do the same for each player.
4. **Send everyone the player page address once**, in the table channel: the dashboard address with
   `/player` at the end, for example `https://<your dashboard address>/player`. It needs no private link.
5. **Tell players to open their link once.** The page remembers it on that device, so they can
   bookmark it or put it on the home screen.

## The D&D helper address

Nothing to send. At the bottom of My character, the card **Your Claude connector** (tap it to open
it) shows the web address for the D&D helper. A player copies it, opens Claude, Settings, Connectors, **Add custom
connector**, pastes it and presses **Connect**, then signs in with their own email (Cloudflare mails a
code). If the card or the web address is missing, the helper is not set up for that player yet: ask
Gnuminator.

## Later

- **Copy link** copies a player's link again.
- **New link** makes a fresh one and turns the old one off. Use it for a lost phone or a link sent to
  the wrong person, then send the new one by DM.
- **Remove** turns a link off without a new one.
- A player who sees **Ask your GM** on My character owns no character yet. Give them ownership in
  Foundry: in the Actors tab, right-click the character, **Configure Ownership**, set the player to
  **Owner** (steps in [When a character dies](death-and-new-characters.md)).

Trouble with the tool or a link: ask Gnuminator. Questions about the game: you decide. More about the
pages: [The dashboard: player pages](dashboard-player-pages.md).

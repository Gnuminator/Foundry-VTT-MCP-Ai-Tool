What it does

Five groups of tools. You switch on the ones a chat needs, so Claude only reads those.

  • Look things up

    Characters, scenes, tokens, combat, journals and compendiums. Ask a plain question and get an answer from your own world.

  • Run the table

    Roll for NPCs, apply damage, set conditions, move tokens, rest the party and post to chat.

  • Prepare sessions

    Quests and journals, encounter budgets, handouts for the players and a log of what happened.

  • Build NPCs

    Make a monster or an NPC from a compendium or from scratch, with features, attacks and spells.

  • Keep the notes

    One Obsidian note per session, a change history and play stats. Notes you edit are never overwritten.

More than a hundred tools in all, and the dashboard can run every one of them without an AI client.

The co-GM dashboard

A page for a second screen. It watches the table in real time and works with or without Claude.

  • Live combat tracker with initiative, hit points, conditions and death saves.
  • A live feed of damage, healing, rolls and the breakdown behind them.
  • Recent Changes: every change Claude made, each with an Undo button.
  • Start and End session markers that the Obsidian notes follow.

Safe by default

The AI proposes. You decide.

  1. Plan. Claude describes the change. Nothing in the game moves yet.
  2. Confirm. You see a diff of what would change, and say yes or no.
  3. Apply, then Undo. The change is recorded. If anything changed since the plan, it is refused. One click takes it back.
  • Every feature has its own switch in the module settings.
  • Game-changing buttons stay off until you press Start session.
  • The player page is built from what players can already see, so hidden creatures and GM rolls never reach it.
  • Nothing calls a paid AI service on its own. The AI works when someone asks Claude.

For the players

Players get a read-only page with the combat order, the live feed, the last recap, the handouts you have revealed and the quests they know about. Unknown creatures read "Unknown creature", and enemies show only a rough health band, never numbers.

After the session

Each play session becomes an Obsidian note. The change history, the roll log and stats per session and per character sit beside it. You can also import a quest note from your prep folder back into Foundry as a GM-only journal, after you confirm the plan.

Get started

Three steps. The GM guide walks through each one.

1. Install the Foundry module

In Foundry, open Add-on Modules, Install Module and paste this manifest URL:

https://github.com/Gnuminator/Foundry-VTT-MCP-Ai-Tool/releases/latest/download/module.json

2. Set up the bridge

The bridge is the small program that links Claude and Foundry. It needs Node.js 24 or newer. 

git clone https://github.com/Gnuminator/Foundry-VTT-MCP-Ai-Tool.git
cd Foundry-VTT-MCP-Ai-Tool
npm install
npm run build

Then add it to Claude Desktop, one entry per tool set. The repository has an example file with all five.

3. Open the dashboard

npm run dev:cogm

It opens at http://localhost:3000. No API key is needed.

Honest limits

  • Foundry 14 with dnd5e 6 only. Other versions and other systems are not supported.
  • Windows only for now.
  • The AI parts need Claude (Claude Desktop or Claude Code). The dashboard does not.
  • You need a GM logged in to Foundry in a browser for the bridge to work.
